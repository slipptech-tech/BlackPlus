# BlackPlus.io
Black+ is a lightweight application that automatically transforms bright websites into elegant dark themes. Designed for comfort and simplicity, it reduces eye strain, improves readability in low-light environments, and provides a modern browsing experience.  Fast, minimal, private, and built to work seamlessly with most websites.

## 📦 Installation Guide

To install **Black+** in your browser (Google Chrome, Microsoft Edge, Brave, etc.), follow these simple steps:

1. **Download the archive:**
   * Go to the main page of this repository.
   * Click the green **`< > Code`** button in the top right corner.
   * Select **Download ZIP** and extract the downloaded archive to a folder on your computer.

2. **Open the extensions page:**
   * Open your browser.
   * Type `chrome://extensions/` in the address bar and press **Enter**.

3. **Enable Developer Mode:**
   * In the top-right corner of the extensions page, toggle the **Developer mode** switch to **ON**.

4. **Load the extension:**
   * In the top-left corner, click the **Load unpacked** button.
   * In the file window that opens, select the folder where you extracted the project files.

Done! The extension will appear in your list, and the dark theme will start working automatically.
